Protocol notes
How this tool follows IndexNow
The destination list is based on the official IndexNow partner registry and may change. Protocol partners share accepted notifications with other participating engines.

      

        
1. Publish the key file
Use a UTF-8 text file named {key}.txt, containing only the key. Put it at the root when possible. If it lives in a subfolder, only URLs within that folder's path scope can use it.

        
2. Validate host & scope
Every URL in one batch must use the same host. The tool checks that the key file matches that host and that submitted URL paths are within the file's allowed scope.

        
3. Send & read the receipt
A single URL uses GET; multiple URLs use JSON POST with a maximum of 10,000 URLs. If browser CORS prevents reading the response, use the generated curl command to inspect the HTTP status.

      

      
IndexNow shares accepted URL-change notices with participating search engines.Read official IndexNow documentation ↗

      
Response codes200 received; 202 accepted, key validation pending; 400 malformed request; 403 invalid key or key file; 422 host or key-schema mismatch; 429 rate limited. Some endpoints may return other codes. A successful response is not an indexing guarantee.
